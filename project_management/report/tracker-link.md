# Учёт задач и передача преподавателю

Команда ведёт единый реестр ответственности и времени в `raci-matrix.xlsx` вместо отдельного публичного таск-трекера. Недельные итоги переданы со слов команды. Время 16 задач восстановлено по памяти в диапазоне 3–5 часов; границы недели не означают точные даты действия.

Перед сдачей разместить весь каталог в общем облаке или репозитории, открыть преподавателю доступ и внести ссылку на каталог в таблицу команды из задания. Ссылка на внешний проект здесь не указана, поскольку команда её не предоставила.
