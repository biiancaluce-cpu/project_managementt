# Распределение задач

Пусть xᵢⱼ = 1, если задачу i выполняет участник j. Максимизируется ΣᵢΣⱼ hᵢpᵢⱼxᵢⱼ, где hᵢ — согласованные часы, pᵢⱼ — индивидуальная предпочтительность 1–5. Ограничения: каждая задача назначена ровно одному участнику; нагрузка каждого от 20 до 32 ч (25–40% от 80 ч). Решение найдено точным динамическим программированием по двум нагрузкам; третья определяется остатком.
